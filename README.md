# Computer Science Quiz

A simple C++ quiz game with 4 multiple-choice questions about computer science and programming.

## Features

- 4 quiz questions
- 4 answer options for each question
- Score tracking
- Immediate feedback after each answer

## How it works

The program displays one question at a time.
The user types **A**, **B**, **C**, or **D**.
At the end, the final score is shown.

## Requirements

- A C++ compiler
- A terminal or command prompt

## How to run

Compile the program:

```bash
g++ main.cpp -o quiz
```

Run the program:

**Windows**
```bash
quiz.exe
```

**Linux/macOS**
```bash
./quiz
```
